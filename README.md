# Our instrument: -Loop Station-

**Play it here:** https://idbcourses.github.io/ht26-a1-group-intermediate-2/


**Group:** Bence, Fabian, Ishkanda, Katarina


The idea of this project is to create a "loop station" where the user plays various notes,
which are then recorded, saved, and then "looped". The user can then add additional notes
to their loop and iterate upon it to create various beats. The concept is similar to a DJ deck.


## How to play
| --------------------------------------------------------------------------------|
| Key                           |  What it does                                   |
| --------------------------------------------------------------------------------|
| `B`                           |  Plays the sample loop when held                |
|---------------------------------------------------------------------------------|
|`Space`                        |  Plays the loop                                 |
| --------------------------------------------------------------------------------|
| `F`, `V`, `C`                 |  Adjusts the knob                               |
| --------------------------------------------------------------------------------|
| `1`, `2`, `3`                 |                                                 |
| `Q`, `W`, `E`                 |  Adjusts the Bass                               |
| `A`, `S`, `D`                 |                                                 |
| --------------------------------------------------------------------------------|
| `7`, `8`, `9`                 |                                                 |
| `U`, `I`, `O`                 |  Adjusts the High                               |
| `J`, `K`, `L`                 |                                                 |
| --------------------------------------------------------------------------------|
| `Left Arrow`, `Right Arrow`   |  Adjusts the Octave                             |
| --------------------------------------------------------------------------------|


- Instructions -
*F,V,C* are directional. When pressed sequentially in a clockwise direction, the knob increases;
Anticlockwise motion decreases the knob. For the actual loop, the key presses are automatically
recorded after pressing the audio-producing keys. The loop then stores up to 5 seconds of the
user's audio, and pressing *space* plays the loop.
